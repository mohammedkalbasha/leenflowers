# 🌸 متجر لين للزهور | Leen Flowers Boutique & Store Management

منصة تجارة إلكترونية ولوحة إدارة متكاملة وفاخرة لمتجر زهور وهدايا طبيعية في الأردن، مصممة بأعلى معايير تجربة المستخدم (UI/UX) مع نظام طلب مرن عبر الواتساب وقاعدة بيانات دائمة (SQLite) ودعم رفع ألبومات صور متعددة للمنتجات.

---

## ✨ المميزات الرئيسية للمشروع (Key Features)

### 🛍️ 1. واجهة المتجر وتجربة المشتري (Storefront Experience)
- **🎨 هوية بصرية فاخرة (Luxury Blush Aesthetic):** ألوان متناغمة، تأثيرات زجاجية (Glassmorphism)، وخطوط عربية حديثة مع حركة سلسة وتجاوب كامل مع الهواتف الذكية.
- **🏷️ تصنيفات وكتالوج ديناميكي:**
  - باقات ورد طبيعي
  - بوكسات ورد وهدايا فاخرة
  - فازات واستاندات كريستال
  - تنسيقات أعراس ومناسبات وتخرج
- **🖼️ ألبوم صور تفاعلي لكل باقة:** نافذة استعراض تفاصيل المنتج مع سلايدر وصور مصغرة متعددة للتعرف على زوايا التنسيق وتفاصيل نوع الورد وطريقة العناية به.
- **🛒 سلة مشتريات فورية (Cart Drawer):** إضافة سريعة، تعديل الكميات، حساب المجموع التلقائي دون الحاجة لإعادة تحميل الصفحة.
- **📍 نظام استلام وتوصيل ذكي ومخصص:**
  - **🏬 استلام من المحل (Store Pickup):** مجاناً (0.00 د.أ) بدون أي حقول زائدة، يكتفي ببيانات المشتري وموعد الاستلام مع عرض بطاقة الفرع وخريطة Google Maps.
  - **🚗 توصيل إلى العنوان (Delivery):** مع خيارين:
    - *التوصيل لي شخصياً:* يعتمد على بيانات المشتري مباشرة.
    - *إهداء لشخص آخر:* إظهار حقول اسم ورقم هاتف المستلم لتنسيق السائق معه.
  - **🎯 تحديد الموقع الجغرافي (GPS Geolocation):** زر بنقرة واحدة لجلب إحداثيات موقع الزبون ووضع رابط خرائط Google للسائق مباشرة.
  - **💌 كرت إهداء مجاني:** خانة لكتابة إهداء خاص وتوقيع يُرفق مع الورد.
- **💬 تأكيد الطلب المباشر عبر WhatsApp:** توليد رسالة واتساب منسقة ومفصلة برقم الطلب الرسمي وإرسالها مباشرة إلى رقم المتجر.

---

### ⚙️ 2. لوحة الإدارة وقاعدة البيانات (Dashboard & Admin Panel)
- **📊 إحصائيات المتجر اللحظية:** إجمالي المنتجات، الباقات المتوفرة، الطلبات الجديدة، وإجمالي المبيعات.
- **🌹 إدارة باقات الزهور (قاعدة بيانات SQLite الدائمة):**
  - **🔍 بحث وفلترة فورية:** بحث بالاسم والوصف، وفلترة حسب الأقسام وحالة التوفر.
  - **📸 ألبوم صور متعدد لكل منتج:**
    - دعم سحب وإفلات أو اختيار **عدة صور معاً** من جهاز الكمبيوتر أو الهاتف مباشرة (Drag & Drop File Upload).
    - دعم إضافة روابط صور خارجية (URLs).
    - تعيين أي صورة كصورة رئيسية للمتجر بنقرة زر واحدة ⭐.
  - **✏️ إضافة وتعديل وحذف المنتجات:** تحكم كامل بالأسعار، السعر قبل الخصم، الشارات، الأقسام، والأوصاف.
  - **⚡ تبديل فوري لحالة التوفر:** كبسولة تفاعلية لتبديل حالة التوفر (متوفر بالمحل / نفد) فوراً.
- **📋 إدارة سجل الطلبات:** حفظ كل طلب وارد من الزبائن في قاعدة بيانات SQLite مع رقم تسلسلي وتاريخ ووقت الطلب.
- **🖨️ طباعة كرت الإهداء وإرسالية السائق:** قسيمة مطبوعة A5/A6 أنيقة تضم كرت الإهداء الخاص، تفاصيل السائق، والمنتجات بدون ظهور واجهة الموقع (`no-print`).
- **🔧 إدارة إعدادات المتجر:** تعديل رقم الواتساب المعتمد، اسم المتجر، وروابط منصات التواصل.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الواجهة الأمامية (Frontend):**
  - Semantic HTML5 (مهيأ لمحركات البحث SEO والملاحة السريعة).
  - Vanilla CSS3 (نظام تصميم كامل ومبني خصيصاً بدون أطر عمل خارجية لضمان السرعة الفائقة).
  - Vanilla JavaScript ES Modules (منظم ضمن وحدات: `store`, `cart`, `api-client`).
- **التجميع والأداء (Bundler):**
  - مجمع أصلي مخصص وخفيف بدون اعتماديات (`scripts/build.js`) ينتج حزمة موحدة متوافقة مع المتصفحات وتعمل بدون مشاكل CORS محلياً أو على أي استضافة.
- **الخادم الخلفي (Backend):**
  - Node.js Native HTTP Server (`server.js`) مع REST API Router وStatic File Server.
- **قاعدة البيانات (Database):**
  - محرك SQLite الأصلي المدمج في Node.js (`node:sqlite`) عبر [db.js](db.js) لسرعة خيالية واستهلاك موارد معدوم.

## 🚀 طريقة التشغيل محلياً (How to Run Locally)

### المتطلبات الأساسية:
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 20 أو 22 فما فوق).

### خطوات التشغيل:
1. **استنساخ المشروع (Clone):**
   ```bash
   git clone https://github.com/USERNAME/flower-store.git
   cd flower-store
   ```

2. **تشغيل السيرفر:**
   ```bash
   node server.js
   ```

3. **فتح الموقع في المتصفح:**
   - 🌸 **واجهة المتجر الرئيسية:** [http://localhost:3000](http://localhost:3000)
   - ⚙️ **لوحة التحكم والإدارة:** [http://localhost:3000/dashboard.html](http://localhost:3000/dashboard.html)

4. **إعادة بناء ملفات الـ JS (عند التعديل على الملفات الفرعية):**
   ```bash
   node scripts/build.js
   ```

## 📤 طريقة رفع المشروع إلى GitHub (Push to GitHub)

إذا كنت ترغب برفع هذا المستودع إلى حسابك على GitHub، اتبع الخطوات التالية في سطر الأوامر (Terminal / PowerShell):

```bash
# 1. التأكد من حالة الملفات
git status

# 2. إضافة جميع الملفات إلى التتبع
git add .

# 3. حفظ التغييرات (Commit)
git commit -m "feat: complete Leen Flowers store platform with multi-image album and store pickup flow"

# 4. تعيين الفرع الرئيسي
git branch -M main

# 5. ربط المستودع بمستودعك على GitHub (استبدل الرابط برابط مستودعك الخاص)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git

# 6. رفع الكود
git push -u origin main
```

## 🌐 النشر والاستضافة (Deployment)

المشروع مصمم ليكون فائق المرونة:
- **استضافة كاملة (Full Stack):** يمكن تشغيله على أي خادم سحابي أو VPS يدعم Node.js (مثل Render, Railway, DigitalOcean, Heroku) عبر أمر `node server.js`.
- **استضافة ثابتة (Static Web):** يمكن رفعه كواجهة ثابتة على **GitHub Pages** أو **Vercel** أو **Netlify** وسيعمل المتجر ولوحة التحكم بنظام التخزين المحلي (LocalStorage) بصفر إعدادات!
